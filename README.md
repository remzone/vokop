# Vokop

OpenWrt application based on [Forkop](https://github.com/ushan0v/forkop), adding VK TURN transport subscriptions and a versioned management contract for a separately adapted 3x-ui panel.

## Development status

Implementation and validation are in progress. This initial commit is not an installable release. Do not run upstream installation commands against this repository yet.

No production credentials or panel endpoints belong in this repository. Final documentation will distinguish automated checks, build checks, and tests requiring real OpenWrt hardware.
