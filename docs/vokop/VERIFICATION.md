- Backend: **60/60 shell-наборов**, **55/55 Python-тестов** VK TURN, включая четыре parser→cache→generator интеграционных сценария. **61 ucode-модуль** синтаксически компилируется host ucode. Дополнительно те же **55 тестов** и компиляция **61 модуля** прошли с настоящим target ucode из SDK OpenWrt 24.10.4 x86/64 через его musl loader, без запуска служб.
- Управление: контракт, durable ACK/retry без повторного выполнения при ошибке POST, изоляция очереди при переоформлении устройства, свежая проверка срока каждой команды, локальное разрешение, UI старт/остановка и повторные клики.
- `vokop-fetch`: Go unit/race tests и vet; локальные TLS-моки проверяют HTTPS, redirect, лимиты и прямой маркированный DNS.
- VK TURN: `go test ./...`, `go test -race -count=1 ./...`, `go vet ./...`, `go mod verify` — PASS; 14 top-level тестов, 25 test/subtest pass events.
- Реально скомпилированы **20 статических Linux ELF**: транспорт + fetch для amd64, arm64, armv7, armv6, 386, mips, mipsle, mips64, mips64le, riscv64. Все SHA256 проверены. Бинарники не запускались как туннели.
- Подробные размеры/хеши бинарников: [`transport/verification/2026-10-30.json`](../../transport/verification/2026-10-30.json).

Тесты сетевого/служебного поведения использовали заглушки; они не меняли сетевые настройки хоста.

## Исправления после реальной сборки

- Рецепты Go-пакетов корректно определяют корень исходников через symlink SDK feed.
- Статическая сборка явно задаёт `CGO_ENABLED=0` и внутренний linker (стандартный Go helper SDK требует внешний linker).
- `GOFLAGS=-buildvcs=false` действует также на `go list` внутри SDK; временный build каталог не обязан быть Git checkout.
- Добавлен явный `VOKOP_GO_ROOT` для совместимого локального официального Go: штатный Go 1.23 SDK 24.10.4 недостаточен для транспорта 1.25.5. Без этой опции сохраняется обычный `golang/host` feed.
- Регрессионные тесты обновлены под строгий HTTPS, новые init scripts и намеренно отключённый старый release workflow; проверка безопасности не ослаблена.

## Границы результата

- Нет проверки на настоящем роутере: установка, procd/nftables/DNS/Wi-Fi, реальное VK-соединение, нагрузка и восстановление после потери питания ещё требуют стенда.
- Нет универсальной совместимости «везде, где работает AmneziaWG». База требует OpenWrt 24.10+; каждую модель/прошивку нужно проверять отдельно.
- Успешная cross-компиляция не доказывает поддержку конкретного CPU ABI/ядра/объёма flash. amd64 транспорт занимает около 15 MB **до сжатия**, отдельно нужен fetch, sing-box и остальные зависимости.
- «Процесс запущен»/«порт открыт» не означают исправный туннель: runtime watchdog делает HTTPS-проверку через SOCKS; в тестах этот путь подменён.
- Восстановление пары config/plan при ошибке записи не является доказанным полным откатом сетевых изменений.
- Сервер обязан сам прекращать доступ по сроку/отзыву подписки; локальный watchdog не заменяет авторизацию.
- Старый автоматический installer/release pipeline остаётся отключённым. `build.sh` — только частичные пакеты; используйте целевой SDK по [`TEST_AND_DEPLOY.ru.md`](TEST_AND_DEPLOY.ru.md).
- Интеграция с настоящим экземпляром 3x-ui и аппаратный smoke test не проводились.
