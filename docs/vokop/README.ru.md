# Vokop: документы интеграции

Vokop — самостоятельный форк [Forkop](https://github.com/ushan0v/forkop) с транспортом [VK TURN Proxy](https://github.com/cacggghp/vk-turn-proxy). Это не официальный Podkop/Forkop и не новый нативный протокол sing-box.

- [Контракт API и подписки](CONTRACT.ru.md).
- [Готовый запрос агенту в форке 3x-ui](PANEL_AGENT_PROMPT.ru.md).
- [Сборка, стенд, восстановление и совместимость](TEST_AND_DEPLOY.ru.md).
- [JSON Schema](schemas/) и [нерабочие демонстрационные данные](examples/).

Код панели здесь **не реализован**. Агент панели должен реализовать контракт из этого репозитория, сохранив существующие функции 3x-ui. Адреса `.example`, UUID и ссылки в примерах являются демонстрационными и не дают доступа к сервису.

До проверки на настоящем OpenWrt не считать проект готовым производственным релизом. Успех unit-тестов или сборки Linux-бинарника не подтверждает прохождение пакетов через настоящий TURN/VLESS на роутере. Фактические результаты тестирования должны сопровождать конкретный коммит.
